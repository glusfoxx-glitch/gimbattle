# Gimbattle

À partir de l'archive zip gim-battle jointe, refais à l'identique l'application pour qu'on puisse y jouer en ligne dans le navigateur avec un système de partie hébergée avec un code perso. Vraiment tu n'auras rien à ajouter de plus dans le jeu à part le système multijoueur mais sinon il va vraiment falloir que tu refasses le jeu à l'identique. Prépare la version web en conservant le jeu à l'identique et en utilisant WebRTC pour les parties avec code de salon.
